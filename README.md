# Cifrador XOR · Ejercicio de Python

Práctica de operaciones XOR y transformación reversible de texto.

## Archivo principal

[`xor_cipher.py`](<xor_cipher.py>) contiene el ejercicio. El repositorio conserva su nombre histórico para mantener los enlaces existentes.

## Qué permite revisar

Lee el punto de entrada, los datos de ejemplo y el resultado de la operación. Contrasta los datos de entrada con la salida antes de extender el ejercicio.

## Alcance

El archivo de entrada real es `xor_cipher.py`. La generación de claves y el esquema de este ejercicio no sustituyen una implementación criptográfica adecuada para proteger información real.

## Ejecutar la demostración

Con Python 3 instalado:

```powershell
python xor_cipher.py
```

No requiere dependencias externas.
